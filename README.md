# BookBot

> 📚 **Learning project** — built while following the [boot.dev](https://boot.dev) back-end path. Kept as a record of my progress; not actively maintained.

Reads a book from a text file and reports word count and character frequency.

**Stack:** Python

## Run it

```bash
python3 main.py
```
